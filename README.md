# MyWipApp

Aplicação simples para controlo de projectos em andamento. Dados guardados em ficheiros JSON.

Requisitos:
- Node.js 14+

Instalação e execução:

```bash
npm install
npm start
# abrir http://localhost:3000
```

Funcionalidades:
- Listar projectos
- Adicionar, editar e eliminar projectos
- Dados persistem em `data/projects.json`
